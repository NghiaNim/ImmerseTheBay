# Coffee demo delivery plan

Use the existing Tenin phone and Air 2 Ultra app. The default course orders coffee in three scenes: the barista takes the order, pours milk and hands over the cup. Dog greeting, date and convenience-store courses stay available. Remove An Afternoon at Home from new course entry points and preserve access to existing review records. The original XREAL SDK 3.1 reference stays available for comparison.
